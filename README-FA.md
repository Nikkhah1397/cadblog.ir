# راهنمای سریع کدبلاگ

## افزودن مطلب جدید
1. در پوشه‌ی `content/posts` یک فایل جدید با پسوند `.md` بسازید (مثلاً `my-post.md`).
2. بالای فایل این بخش را بنویسید (دقیقاً با سه خط تیره):

```
---
title: "عنوان مطلب"
date: 2026-11-10
category: piping
tags: [piping, tutorial]
summary: "خلاصه‌ی یک‌خطی برای کارت مطلب و گوگل"
---

متن مطلب اینجا...
```

3. دسته‌ها و برچسب‌های مجاز در فایل `config.yaml` هستند.
4. فایل را در گیت‌هاب ذخیره (Commit) کنید؛ سایت خودکار به‌روز می‌شود.
5. مطلب پیش‌نویس: خط `draft: true` به بالای فایل اضافه کنید.

## افزودن منبع به کتابخانه
فایل `data/library.yaml` را باز کنید و یک بلوک را کپی و ویرایش کنید.

## تست روی کامپیوتر (اختیاری)
```
pip install -r requirements.txt
python build.py
```
سپس پوشه‌ی `public` ساخته می‌شود.
